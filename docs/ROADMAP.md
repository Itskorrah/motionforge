# Product maturity and next milestones

## Implemented now (tested locally)

- Deterministic Chrome frame loop and H.264/AAC export
- Closed-form physics including under/critical/over damping
- Original seeded PCM score and exact beat-to-cut grid
- CLI project creation and editable validated specs
- Adaptive wide, portrait and square Canvas compositions
- Four visual motifs with beat-driven physical movement
- Automated all-frame defect detection + per-shot storyboard
- Optional API-powered creative drafts and multimodal per-shot critic
- Bounded safe revision loop, QA reports, non-zero threshold failure
- Unit tests, local smoke rendering, GitHub CI and manual rendering workflows
- Optional Evolve software-improvement integration, not runtime coupling

## Not yet claimed

- Arbitrarily complex storyboarding from one natural-language sentence without manual corrections
- Full professional typographic shaping, asset management, image/video import, 3D or character animation
- Voiceover, subtitles, commercial-music import, licensed sound libraries or mastering suite
- GUI editor, interactive timeline, batch manager, real-time previews or cloud queue
- Automated confidence in artistic taste, watch-every-pixel multimodal video reasoning
- Browser-proof appearance across host machines/fonts, streaming video for hours, multi-GPU rendering
- Hosted GitHub workflow execution or paid vision results until credentials/minutes are available

## Proposed next deliverables (in order)

1. Reference-based art direction (brand kit, per-shot layout presets, protected areas, typography audit).
2. Explicit audio lanes and optional external music/voiceover import with rights metadata, mixing and loudness targets.
3. Source asset manifest and properly licensed image/video compositor.
4. Scene timeline JSON with independent entrances/exits, captions and more expressive spring rig primitives.
5. Review dashboard with scrubber, QA heatmap and approve/reject controls.
6. Batch job queue, caching and reproducible render manifests/checksums.
7. Wider eval suite with multiple briefs, scene snapshots at shot boundaries and regressions across aspect ratios.

Do not prematurely replace the renderer or add paid infrastructure without measured need. Improve using Evolve audit/verify as optional development process.
